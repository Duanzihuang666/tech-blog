## 欢迎

这是我的第一篇博客文章，博客基于 **Hugo + GitHub Pages** 搭建。

发布流程约定：

1. 新文章放在 `content/posts/` 目录下
2. frontmatter 必须包含 `title` / `date` / `tags` / `author` 四个字段
3. 提交 Pull Request
4. 合并到 `master` 分支后由 GitHub Actions 自动构建并部署
